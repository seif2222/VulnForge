# Bundled fonts

Both fonts ship inside the build so the dashboard works fully offline (spec 4/5: no CDN).

- JetBrains Mono (variable, latin subset) - SIL Open Font License 1.1
  https://github.com/JetBrains/JetBrainsMono
- Inter (variable, latin subset) - SIL Open Font License 1.1
  https://github.com/rsms/inter

Downloaded from Google Fonts on 2026-11-22; woff2 files are unmodified subsets.
